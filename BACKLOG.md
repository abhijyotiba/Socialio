# Backlog

Things noticed during a phase that belong in a different phase, or improvements to defer. **Do not fix these in the current phase — write them here and move on.**

Format:

```
- [ ] **Title** — short description. Belongs in: Phase N (or "later"). Discovered: YYYY-MM-DD.
```

When starting a new phase, scan this list for anything that belongs to that phase and either pull it into the phase doc or decide to punt again.
